# cafe-expresso

Descrição
Sistema de autoatendimento para cafeteria que permite ao cliente montar pedidos, selecionar produtos, calcular o valor total automaticamente e acompanhar o status do pedido.
Objetivo
Agilizar o atendimento, reduzir filas e evitar erros nos pedidos.
 Funcionalidades

* Cadastro de produtos
* Adição de itens ao pedido
* Cálculo automático do total
* Controle de status do pedido

 Estrutura

* Produto
* ItemPedido
* Pedido

 Linguagem

Python
